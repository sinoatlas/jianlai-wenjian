# 剑来·问剑

一套以《剑来》人物、招式与性格为主题的家庭卡牌桌游，面向10-12岁玩家。每名人物只有一个技能，配合剑招、符箓与武器形成互动，支持1v1、2v2和五人身份局。

当前版本：**v0.4 插画版**。共126张卡牌，39张原创插画；每局最多8轮。

## 下载与开始

1. 点击仓库的 **Code → Download ZIP**，解压后保留文件夹结构。
2. 阅读[完整规则PDF](output/pdf/规则与设计说明.pdf)。PDF有目录和书签，共12页。
3. 打印[双面卡牌PDF](output/pdf/双面卡牌.pdf)：A4竖向、实际大小/100%、双面长边翻转。先打印第1-2页检查对齐。
4. 沿虚线裁切，单张63×88毫米。全套使用14张A4纸，可放入不透明牌套。

[正面卡牌PDF](output/pdf/正面卡牌.pdf)适合仅打印正面后放入不透明牌套。PDF已内嵌图片，可以单独下载使用。

## 三种玩法

|玩法|人数|立即获胜条件|8轮结束仍未分胜负|
|---|---:|---|---|
|问剑|2人，1v1|对手退场|依次比较势分、在场人数、剩余体力；全相同则平局|
|并肩|4人，2v2|对方两人全部退场|依次比较队伍势分、在场人数、剩余体力；全相同则平局|
|问鼎|5人身份局|按主公、忠臣、奸臣、内奸目标判定|平局|

身份配置为1主公、1忠臣、2奸臣、1内奸。完整胜负顺序见规则PDF第6页。每轮是所有在场玩家按顺序各行动一次；第5轮停止回复体力，第7轮起每轮结束同时流失1点体力。

## 卡牌组成

|类别|数量|
|---|---:|
|人物牌|12|
|游戏牌，含六件武器|90|
|身份牌|5|
|阴阳鱼体力牌|9|
|规则提示牌|10|
|合计|126|

每回合通常摸2张牌、最多2个动作，手牌上限5。人物基础体力4，身份局主公5；体力降到0立即退场。

## 版本与创作说明

插画由内置生图按原著意象原创生成，非动画官方立绘。人物名称、能力概念与性格取自《剑来》，摸牌、动作与伤害数值属于桌游转译。参考来源保留在规则文档中。

这是家庭试玩版本，尚未经真人胜率与时长验证。欢迎通过Issues反馈具体对阵、先后手、结束轮数和争议步骤。
